## 固定的角色和形式
- 旁白：温柔亲切的女声。豆豆：小仓鼠，童声，好奇、热心，偶尔犯小错。两人可以一问一答。
- 结构：
  1. 开头 3–5 秒用一个能抓住孩子的小问题或小悬念；
  2. 在场景里用实物演示讲清概念；
  3. 讲出规则或方法，说法和教材一致；
  4. 练一练：读题后停顿约 3 秒（画面倒计时），再揭晓答案；
  5. 豆豆说一句总结。片尾卡自动生成，不用写。
- 按指定的讲法来组织内容；场景和物体要贴合主题，让孩子觉得有趣。两条视频的物体不要相同。
- 版权要求：
  - 情境、例题数字、画面都要原创；
  - 不照搬教材插图、人物、原题和原文；
  - 不出现任何已有的卡通角色或品牌。

## 请按这个格式返回（两课各一份）
1. 适合年龄或年级、一句话教学目标。
2. 配音脚本：一个 JSON 数组，每句是
   `{"id": "英文短名", "speaker": "narrator" 或 "doudou", "say": "要念的话，数字写成汉字，每句不超过约 20 字", "caption": "屏幕字幕，用阿拉伯数字，重点用 <b></b>，两行用 <br>", "gap": 句后停顿秒数（默认 0.45，练一练读题后用 3.2）, "marks": {"事件名": "这句话里触发画面动作的关键词"}}`。
   全部配音合计约 180–260 字，按内容需要增减。关键词必须原样出现在 say 里；同一个字出现多次时，写成 ["字", 第几次（从 0 开始）]。
   多音字：say 里的“数、重、长、量、行、差、称、率、倒、还、只、种”每一处都要标音，写成 字[拼音]，例如“数[shǔ]一数[shǔ]”“分数[shù]”“不漏也不重[chóng]”“长[cháng]方形”。关键词（marks）照原字写，不带标音。
   marks 的事件名在整条视频里不能重复，也不能和任何句子的 id 同名（比如句子 id 是 quiz，就不要再用 quiz 作事件名）：句子开始的时刻本身就是事件，名字是句子 id。
3. 分镜：逐句说明画面上发生什么，引用上面的事件名，说明用哪些道具、豆豆的哪些动作、镜头机位、大数字、标签、重点讲解。
4. 练一练：题目、答案。
5. 片尾总结：一句话，15 字以内。
6. 音效：`[{"at": "事件名", "type": "音效名"}]`。
7. 你用 Python 验算过的全部算式。
